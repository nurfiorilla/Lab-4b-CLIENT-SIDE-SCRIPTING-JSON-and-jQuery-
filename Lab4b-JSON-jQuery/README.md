## Project Description
This project demonstrates JSON data handling, JavaScript fetch(), and jQuery DOM manipulation.

## Project Files
1. books.json - Contains two book objects.
2. books.html - Retrieves and displays JSON data.
3. jquery-dom.html - Demonstrates jQuery DOM operations.

## How to Run

1. Download and keep all three files in the same folder.
2. Open the project folder in notepad c++ or Visual Studio Code.
3. Install the Live Server extension (if using Visual Studio Code).
4. Right-click books.html.
5. Select Open with Live Server.
6. View the book information in the browser.
7. To test jQuery, open jquery-dom.html with Live Server.
8. Confirm that Original Text changes to Modified Text, the myDIV area has a coral background and padding, and clicking the button displays an alert.
9. Do not open books.html directly using file://; the lab requires a local server for fetch().
